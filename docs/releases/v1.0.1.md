# Art Prep 1.0.1

Art Prep now has its own app icon: a sloth artist holding a brush, painted in a delicate Chinese
ink-wash style on warm rice paper. The original artwork and generation prompt are included in the
repository, and the build packages the icon at standard and Retina sizes for macOS.

Download **Art-Prep-v1.0.1-macOS-arm64.zip**, unzip it, and replace the earlier **Art Prep.app** in
Applications. Requires an Apple Silicon Mac, macOS 14 or later, and GIMP 3. This build is locally
signed, not Apple-notarized.

Photo editing and export behavior are unchanged from 1.0.0. This update changes the app icon and
bundle version only. The build verifies that macOS decodes all eight icon representations.
The extracted app's code signature, icon reference, and version metadata were verified.
