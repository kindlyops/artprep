# Art Prep 1.0.0

Prepare photos of paintings with a plain background, using a native Mac interface and local GIMP.
Mark the outside of the artwork and wood, review the cutout, then export.

- Outline editing with point dragging, insertion, deletion, undo, zoom, and optional edge refinement.
- Warm off-white background by default, with adjustable color and margins.
- Batch exports: editable GIMP XCF, full-resolution sRGB JPEG, and 2000-pixel social JPEG.
- Save and reopen outline projects; a command-line interface supports repeatable exports.
- Source photos remain untouched. No photo uploads or cloud processing.

## Download and run

Download **Art-Prep-v1.0.0-macOS-arm64.zip**, unzip it, and move **Art Prep.app** to Applications.
Requires an **Apple Silicon Mac**, **macOS 14 or later**, and **GIMP 3** installed in Applications.
This personal build is locally signed and **not Apple-notarized**; normal macOS downloaded-app
security checks still apply. An Intel build is not included.

See the [usage and build guide](https://github.com/kindlyops/artprep/blob/v1.0.0/README.md).
