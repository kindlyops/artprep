Art Prep.
Your artwork, ready to post.

A small native Mac app that turns a photographed painting and its wooden backing into a clean composition on a plain background.

Add photos, mark the outside edge of the wood, review the cutout, and export. The app automates the GIMP steps used for the four paintings already completed in this conversation.

DecisionProposed default
ProcessingOn your Mac, through your installed GIMP 3. No photo uploads or model downloads.
BackgroundWarm off-white, #F3EFE7, with a color picker.
Artwork boundaryYou mark and approve it; the app can refine the nearby edge.
DeliveryA double-clickable .app, its source code, and a short usage guide.

This is a proposed application, not an already implemented one. Choosing the artwork boundary remains a human step. The app will automate the rest.

The workflow

One outline per photo.

StepYour actionApp behavior
1 · AddSelect one or several JPEG or PNG files.Shows a photo queue and a color-managed preview.
2 · OutlineClick around the outer edge of the wooden backing. Use four corners for a rectangular board; add points for irregular edges.Shows a closed outline. Drag points to adjust them; zoom, undo, insert, or delete a point.
3 · ReviewCheck the cutout against the selected background.Offers optional edge refinement, a before/after view, and margins. Refinement can be turned off where an object touches the frame.
4 · ExportChoose an output folder and export the ready photos.Runs jobs sequentially, reports progress, and provides links to the results. A failed photo does not discard the others.

The default composition uses a 4:5 canvas for portrait artwork and a 3:2 canvas for landscape artwork, matching the recent edits. The app fits the complete outlined artwork within the margins.

Each photo produces an editable GIMP project, a full-size JPEG, and a social JPEG with a 2,000-pixel long edge and sRGB profile. The project contains the masked artwork, the background, and a hidden cropped reference layer.

Exposure, white balance, and the painting itself stay as photographed. This tool prepares the surroundings; it does not repaint or generate artwork.

Implementation approach

Native controls. The existing GIMP workflow.

A Swift/AppKit interface handles file selection, previews, outline editing, and progress. A local JSON job file records the source path, image coordinates, outline, background, margins, and output settings. The app passes validated jobs to a bundled Python script running inside GIMP.

The renderer generalizes the scripts already used here: create a mask, compose on the chosen background, save the layered project, and export color-managed JPEGs. All coordinates refer to the correctly oriented source image, independently of preview zoom or window size.

Considered approachTrade-off
Native app + guided outline · recommendedDirect control over what is preserved, while automating the repetitive editing and export work.
Fully automatic background detectionLess clicking, but uncertain separation where cords, charts, shadows, and wood touch. Deferred from the first version.
Codex-operated command-line toolSmaller build, but would still require Codex or terminal use. Does not meet your preferred workflow.

The job file also allows Codex to reproduce the same work without operating the interface. Saved selections can be reopened and re-exported with another background color.

The app relies on the GIMP installation already on this Mac. If GIMP is missing or incompatible, it explains what to fix before export. No extra image-processing service is required.

Implementation will include geometry and job-validation tests, renderer checks with small fixtures, and a visual end-to-end check using the existing painting examples. The final handoff includes the app, source, and concise instructions for adding photos, correcting outlines, and exporting.

Evidence: the four completed painting edits; the working local GIMP 3.2.6 installation; the existing edge-refinement and GIMP export scripts. Assumptions: JPEG/PNG inputs, user-reviewed outlines, no automatic perspective or exposure correction.
