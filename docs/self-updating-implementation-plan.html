Implementation plan · proposed execution

Self-updating Art Prep

For agentic workers: use superpowers:executing-plans for native execution, recommended here because the packaging and release tasks depend closely on each other. Alternatively use superpowers:subagent-driven-development if the user selects that method. Complete the unchecked steps in order; read the approved design before executing.

Goal: users can discover, download, verify, install, and relaunch a new Art Prep release from inside the application without losing work.

Architecture: a GUI-only Sparkle controller owns updates. The existing release script embeds and signs Sparkle, notarizes the app, and publishes a verified signed feed and ZIP through a draft GitHub release. The public workflow continues dispatching only merged source to the private builder.

Stack: Swift 6, SwiftUI/AppKit, Security, Sparkle 2.10.0, Bash, Python 3.13 standard library for release metadata, existing pytest and GitHub CLI.

Spec: approved self-updating design, commit 96f8e15. Source root: outputs/ArtPrep-Source in this task workspace. Private controls: sibling outputs/ArtPrep-Build.

Global constraints

  • macOS 14 or newer; Apple Silicon release; bundle identifier local.artprep.mac.
  • Automatic checks enabled; unattended installation disabled; no system-profile reporting.
  • Feed: https://github.com/kindlyops/artprep/releases/latest/download/appcast.xml.
  • Full ZIP only; require signed feed and verification before extraction.
  • Developer ID team K5U72ZNJ2W; notarization remains in the explicit login Keychain.
  • Dedicated Sparkle account local.artprep.mac; public key in source, private key only in Keychain.
  • No changes to the source-photo, outline, renderer, or project formats.
  • Feature branches and PRs; commit every development turn. Never run PR source on the Mac runner.
  • Functions at most 100 lines and complexity 8; existing linters and warnings-as-errors remain.

Review focus

ConditionOwner and expected behavior
A second operation starts before deferred install resumesTask 2: recheck workspace lock at callback execution; invoke continuation at most once.
User cancels quit after an update downloadTask 2: outlines and normal quit warning remain; a later manual install can proceed.
Download cache contains mixed or interrupted framework filesTask 1: reconstruct from the checksum-verified archive, never trust a stamp alone.
Draft is incomplete, or main has advancedTask 4: recover only the explicitly selected version and exact merged source; never publish mismatched assets or downgrade latest.
Update accepted but relaunch or GIMP execution failsTask 5: test the installed app, including actual local rendering, rather than declaring success after download.
